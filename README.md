One sentence, at most 200 characters, on a small moment of wonder in everyday life — a make.fun entry for the Everyday Wonder competition.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
